# IVE photo sources

All visible member imagery is based on real photography. No faces or people in these assets were generated or retouched with generative AI.

- `portraits/wonyoung.webp` — clean 720×1280 real Wonyoung portrait used only as the left rail photo layer; all rail typography is native HTML/CSS.
- `wonyoung-left-current.webp` — preserved in the repository for provenance but no longer loaded by the active frontend because it contains flattened decorative typography.
- `hero-current.webp` — real IVE group promotional photograph sourced at 3840×2160 from https://wallpapercg.com/ive-k-pop-wallpapers
- `ive-right-current.webp` — three crops from the same real group photograph, stacked to fit the narrow desktop rail without stretching faces.
- `feature-current.webp` — real IVE group photograph sourced at 1200×800 from https://www.soompi.com/article/1711367wpp/ives-agency-shares-update-on-legal-action-for-malicious-comments-and-defamation

The only processing applied was cropping, resizing, stacking, and WebP compression.
