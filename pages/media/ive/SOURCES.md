# IVE artwork sources and build process

Every visible member face comes from a real photograph. No person, face, facial feature, or member likeness is generated, reconstructed, or replaced with generative AI.

## Real source photographs

- `portraits/wonyoung.webp` — 720×1280 real Wonyoung portrait used by the left artwork.
- `sources/ive-group-wide.jpg` — 3840×2160 real IVE promotional photograph from https://wallpapercg.com/ive-k-pop-wallpapers
- `sources/ive-group-portrait.jpg` — 1365×2048 real IVE group photograph from https://wallpapercat.com/w/full/8/0/1/1004674-1365x2048-mobile-hd-ive-k-pop-background-image.jpg
- `sources/ive-group-black.jpeg` — 1200×800 real IVE group photograph from https://www.soompi.com/article/1711367wpp/ives-agency-shares-update-on-legal-action-for-malicious-comments-and-defamation

## Finished artwork assets

- `wonyoung-left-art.webp` — 1400×2100 luxury editorial rail artwork.
- `ive-right-art.webp` — 1400×2100 lighter group rail artwork.
- `matchday-hero-art.webp` — 2400×900 wide campaign artwork.
- `ive-feature-art.webp` — 1200×800 editorial feature artwork.

The finished WebP files are generated by `scripts/build-ive-artwork.py`. The script uses deterministic Pillow compositing for high-resolution cropping, masks, geometry, typography, colour grading, grain, and line art. It does not perform face editing or generative image synthesis. Website CSS only places, crops, and adds a subtle interface-edge fade to these finished images.
